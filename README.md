# محمد & آيه — دعوة كتب الكتاب والعِزال

## الموسيقى
ضع ملف موسيقى هادئة باسم `music.mp3` داخل `assets/`.

## النشر
ارفع الملفات إلى Repository على GitHub، ثم:
Settings → Pages → Source: GitHub Actions

أي `push` إلى `main` سيعيد نشر الموقع تلقائيًا.

## ملاحظة
الموسيقى لا تبدأ تلقائيًا بسبب قيود المتصفحات؛ اضغط زر ♫.
